# demo：前端演示脚本

一组**零外部依赖**的演示工具与工作流（确定性输出，无需真实数据源），用于在网页时间线上
完整展示 agent 的执行流程：**思考（流式）→ 调用工具 → 结果 → 回答**。

## 运行

```bash
# 项目根目录执行（需先完成 agent/.env 密钥配置，见主 README）
python demo/start_demo.py
```

启动后访问 <http://127.0.0.1:8008>。与 `python main.py` 的区别仅在于：多注册了 3 个演示工具
和 1 个演示工作流（`GET /workflows` 可见 `weather_brief`）。

## 注册内容

| 名称 | 类型 | 作用 | 演示看点 |
|---|---|---|---|
| `get_weather` | 工具 | 查询城市天气（哈希确定性数据） | 单次工具调用的完整卡片 |
| `roll_dice` | 工具 | 掷骰子 | 多参数 Schema、数组结果 |
| `number_stats` | 工具 | 数字统计 | list 参数、浮点 JSON 输出 |
| `weather_brief` | 工作流 | 汇总天气生成简报 | 慢工具（300s 池）+ 工作流编排 |

## 演示台词（配合截图）

| 目标画面 | 输入 | 触发效果 |
|---|---|---|
| 单工具调用闭环 | `北京今天天气怎么样？` | 一次 `get_weather` 调用：思考 → 调用 → 结果 → 回答 |
| 多工具并行编排 | `对比北京和上海的天气，再掷一次骰子` | 同轮多个 tool_call，时间线出现两组卡片 |
| 工作流（慢工具） | `帮我生成一份杭州天气简报` | LLM 编排 `weather_brief`，展示慢池执行 |
| 多轮上下文 | 上一条之后继续 `那杭州和成都哪个更热？` | 二轮对话携带历史，展示上下文管理 |
| 角色切换 | 右上角下拉切到 `data_analyst` 后提问 `统计 [3, 7, 12] 的平均数` | 换提示词 + `number_stats` 数组参数 |

> 提示：`data_analyst` 角色提示词面向数据分析，配合 `number_stats` 演示效果最自然。
